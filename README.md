# Casa Brunetto | Artesãos da Beleza

Site institucional estático (HTML + CSS + JS, sem dependências).

## Estrutura
- `index.html` — página única
- `assets/` — logo, fotos e vídeo

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Editar
- WhatsApp: procure por `api.whatsapp.com` no `index.html`.
- Instagram: procure por `instagram.com/casabrunetto`.
- Serviços do formulário: lista `S` no script no final do arquivo.
